---
title: "Launch Your First Mintlify Documentation Site Fast"
sidebarTitle: "Quickstart"
description: "Set up your Mintlify documentation site step by step. Connect GitHub, write your first MDX page, and deploy — all in under 10 minutes."
---

This guide walks you through everything you need to publish your first Mintlify documentation site. By the end, you'll have a live docs site connected to GitHub, configured with your branding, and ready for content — deployed automatically on every push.

<Note>
  If you haven't created a Mintlify account yet, head to the [Account Setup](/getting-started/account-setup) page for a detailed walkthrough before continuing.
</Note>

<Steps>
  <Step title="Create your Mintlify account">
    Go to [mintlify.com](https://mintlify.com) and click **Get Started**. Sign up with your GitHub account or email address. Once you're in, Mintlify will prompt you to create your first workspace — give it a name and a unique slug that will become your default subdomain.
  </Step>

  <Step title="Connect your GitHub repository">
    From your Mintlify dashboard, click **Connect Repository**. Install the Mintlify GitHub App and grant it access to the repository that contains (or will contain) your docs. If you don't have a repo yet, select **Use a Template** to fork Mintlify's starter repository — it comes pre-configured and ready to customize.
  </Step>

  <Step title="Configure docs.json">
    At the root of your repository, create or update `docs.json` with your site's name, theme, brand colors, and navigation structure. The example below is a minimal starting point:

    ```json docs.json
    {
      "$schema": "https://mintlify.com/docs.json",
      "name": "My Docs",
      "theme": "luma",
      "colors": {
        "primary": "#0F9B5B"
      },
      "navigation": {
        "groups": [
          {
            "group": "Get Started",
            "pages": ["introduction", "quickstart"]
          }
        ]
      }
    }
    ```

    Every page listed under `navigation` maps to an MDX file in your repository. The value `"introduction"` resolves to `introduction.mdx` at the configured docs root.
  </Step>

  <Step title="Write your first MDX page">
    Create `introduction.mdx` in your repository. Every MDX page starts with a frontmatter block that sets the title and description shown in the sidebar and search results:

    ```mdx introduction.mdx
    ---
    title: "Welcome to My Docs"
    description: "Everything you need to get up and running."
    ---

    Welcome! This is your first Mintlify page. Edit this file in your repository
    and push to see your changes live.
    ```

    You can enrich your pages with Mintlify's built-in components — `<Note>`, `<Warning>`, `<Steps>`, `<CardGroup>`, and more — all without importing anything.
  </Step>

  <Step title="Push to GitHub to deploy">
    Commit your `docs.json` and `introduction.mdx` files and push them to your default branch. Mintlify detects the push, builds your site, and publishes it automatically. Your live docs will be available at `your-workspace.mintlify.app` within a minute or two.

    To preview changes locally before pushing, run the Mintlify CLI from your docs directory:

    ```bash
    npx mintlify dev
    ```

    Your site will be served at `http://localhost:3000` with hot reload enabled.
  </Step>
</Steps>
